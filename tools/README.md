# Tools

This folder contains different useful tools to interact and/or transform refi-based data. The tools are structured by the main programming language used to provide the tool.

## How to

If the language folder for your tool not yet exists, just create it and put your tool in a subfolder inside of that language folder. For example:

The `/tools/python` folder contains the `qdc_converter` folder for the QDC to CVS & EXCEL conversion tool
